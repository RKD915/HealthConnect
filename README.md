# HealthConnect
 🏥 Project Description HealthConnect is a full-stack social fitness & health tracking web application built with Node.js, Express, and MongoDB.  It lets users track their personal health (meals & workouts), connect with others through a social feed, and stay motivated via a leaderboard. Key features include:  🔐 Authentication — JWT-based register/login with bcrypt password hashing 🥗 Meal Tracking — Log and view daily meals 🏋️ Workout Tracking — Log and view workout sessions 📣 Social Feed — Create posts, like, comment, and follow other users 🏆 Leaderboard — Rank users by activity 🌐 Frontend — Vanilla HTML/CSS/JS pages (auth, feed, meals, workouts, leaderboard) ⚙️ REST API — Clean MVC architecture with controllers, models, middleware, and routes
